# PromptGate Homebrew tap

```bash
brew install promptgate-ai/tap/promptgate
```

[PromptGate](https://promptgate.dev) is the self-hosted AI gateway as a
single binary. Docs: [docs.promptgate.dev](https://docs.promptgate.dev).

The cask is updated by the release workflow on every release; the
binaries come from install.promptgate.dev, checked against the SHA-256
in the cask. Update with `brew upgrade promptgate`.
