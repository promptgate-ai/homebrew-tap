# PromptGate Homebrew tap

```bash
brew install promptgate-ai/tap/promptgate   # the gateway
brew install promptgate-ai/tap/pgfuzz       # its recall and security test suite
```

[PromptGate](https://promptgate.dev) is the self-hosted AI gateway as a
single binary (Business Source License 1.1);
[pgfuzz](https://docs.promptgate.dev/pgfuzz/) tests a running gateway
(Apache 2.0). Docs: [docs.promptgate.dev](https://docs.promptgate.dev).

The casks are written by each project's release workflow; the binaries
come from install.promptgate.dev, checked against the SHA-256 in the
cask. Update with `brew upgrade`.
